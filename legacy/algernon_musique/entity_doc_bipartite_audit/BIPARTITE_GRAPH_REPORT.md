## 连通分量

分量按 chunk 数计。未加权分布把每个分量算一次；按 chunk 加权才是随机抽一个 chunk 时它所在分量的大小。

- 分量 226 个
- 最大分量：11,422 个 chunk（97.99%），64,871 个实体，9,620 个 title
- 最小分量：1 个 chunk、0 个实体。有实体的最小分量是 1 个 chunk、1 个实体
- 未加权：中位数 1，P90 1，P95 1，P99 2，最大 11,422
- 按 chunk 加权：中位数、P90、P95、P99、最大都是 11,422

### Luna G_raw

B1 最大分量 11,365 chunk（97.50%），226 个以外的其余分量和官方一样，只有 1 到 3 个 chunk。B2 最大分量 11,369 chunk（97.54%）。6–500 这个区间在四张图里都是 0 个分量。

未加权中位数是 1，是因为巨型分量外面几乎全是孤立 chunk。按 chunk 加权之后，中位数就是巨型分量本身。用未加权中位数描述“典型证据组”会把 98% 的语料藏起来。

## Title 收缩

把同一 title 收成一个左侧节点后，gpt-4o-mini B1 有 213 个 title 分量，最大的含 9,620 / 9,838 个 title（97.78%），对应 11,434 个 chunk。B2 最大 title 分量为 9,528 个 title（96.85%）。Luna B1 是 9,564 / 9,838（97.21%）。

跨 chunk 的连接主要是跨 title 的连接，不是同一篇文章被切成多段。

## B1 与 B2 的实体差

同一套规范化 key 上：

| | gpt-4o-mini | Luna |
| --- | ---: | ---: |
| 只出现在 NER | 5,360 | 653 |
| NER 与三元组都有 | 60,728 | 66,281 |
| 只出现在三元组端点 | 41,322 | 18,293 |
| NER 的 chunk 频率 > 1，三元组频率 ≤ 1 | 1,287 | 189 |
| chunk–实体边只在 NER | 17,703 | 3,623 |
| chunk–实体边只在三元组 | 50,280 | 22,767 |

gpt-4o-mini 的三元组阶段制造了大量 NER 列表里没有的端点字符串，所以官方 phrase 节点（102,194）大于 NER 实体（66,088）。Luna 的方向相同，数量较小。

多 chunk 分量几乎没有被这种差异拆开。gpt-4o-mini 的 B1 有 9 个多 chunk 分量，其中只有巨型分量在 B2 里被拆开，而且只是从 11,422 变成 11,342。Luna 是 11 个多 chunk 分量里拆开 1 个。

`American` 是一个清楚的例子：NER 覆盖 887 个 chunk，三元组端点只覆盖 43 个。`British` 是 175 对 44。国家名和年份则两边都很高，`United States` 在 B2 仍有 987。所以 NER 比三元组多出来的边，改变不了“一个巨型分量”这个事实。

高频实体和过滤后的分量见 `HUB_ENTITY_ANALYSIS.md`。
